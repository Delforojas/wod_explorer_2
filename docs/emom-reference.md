# Referencia EMOM

EMOM significa *Every Minute On the Minute*.
En WOD Explorer 2, su resultado es binario: `COMPLETED` o `NOT_COMPLETED`.
`COMPLETED` indica que se completó el WOD prescrito; `NOT_COMPLETED`, que no se completó.
No se registra progreso parcial, minutos alcanzados ni desglose de repeticiones.
Los resultados EMOM no generan marcas personales clasificadas.
Se pueden registrar varios intentos de un mismo WOD EMOM.

Ejemplo: EMOM de 10 minutos, completar 5 burpees al inicio de cada minuto.
El intento se registra como `COMPLETED` si se completa el WOD prescrito o como `NOT_COMPLETED` en caso contrario.
