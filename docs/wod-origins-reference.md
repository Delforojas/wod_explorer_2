# Orígenes de WOD

Cada WOD de WOD Explorer 2 tiene uno de dos orígenes posibles: genérico o personal.

Un WOD **genérico** pertenece al sistema, es público y solo el sistema puede crearlo, modificarlo o eliminarlo. Por ejemplo, el WOD "Fran" (21-15-9 de thrusters y pull-ups) forma parte del catálogo del sistema y es visible para cualquier usuario.

Un WOD **personal** pertenece a un usuario registrado, es privado y solo su propietario puede crearlo, modificarlo o eliminarlo. Por ejemplo, un WOD llamado "Entreno del lunes" creado por un usuario para su propio seguimiento, visible únicamente para él.

Los nombres de WOD no son únicos: un mismo nombre puede repetirse entre distintos orígenes e incluso dentro de la colección personal de un mismo usuario.
