# Prueba del agente Git local

## Estado del repositorio

`git status --short` muestra de forma compacta los archivos modificados,
eliminados o no rastreados en el directorio de trabajo. Sirve para comprobar
qué cambios locales existen antes de continuar con el workflow.

## Rama activa

`git branch --show-current` muestra el nombre de la rama local actualmente
activa. Permite confirmar que la comprobación se realiza en la rama esperada.

## Límite de la prueba

Esta prueba solo documenta comprobaciones Git locales y no debe modificar
código de frontend, backend ni la base de datos.
